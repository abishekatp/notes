# Drone
  In this blog series we are going learn about each and every thing about drones. We will explore such that there is no stone untouched. Building my own drone has been my personel quest since my collage days. So this journey is going to be fun for me also. We will explore both hardware and software part of the drone. First I will try to explain generically about both hardware and software. In case of hardware we will first learn about microcontrollers, motors, sensors, batteries and some other parts. Then we will specifically use Arduino for the demo purpose. Similarly for software we are going to use pseudocode to explain the algorithms and core logics without relying on any specific programming language. We will also have a Rust implementation of the software for the demo purpose.
