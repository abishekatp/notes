# Data Structures and Algorithms

Here I am trying put together my thoughts on some of the topics in the data structures and algorithms as a series of blogs. I will be mostly focussing on core logic of each topic and proving the correctness of those logics. I will also add a pseudocode wherever it is possible. 

### Reference

Mainly I am referencig the book "Introduction to Algorithms" by CLRS(Cormen, Leiserson, Rivest, Stein). Other than that I have learned from various free materials and videos available on the internet. But there may be some differences how I am explaining things. If you are beginner and  expecting clear tutorial kind of thing I highly recommend following the above book(or any other standard book).

#### Notations:

* Throughout the series of blogs we use the array indexing that starts from 1. Other than that one difference we use and access the arrays in the same way we do in any of the common programming languages(like c, c++, Java, Javascript…). 
* I will use objects in some of the places. they will behave in a similar to any common programming languages.
* If we had loop condition j > 0 then loop completes its execution only after j = 0. So an algorithm that refers to the value of j after the full completion of the loop statements will have the value j=0.
* For doing complexity analysis of algorithms, Mostly I will be using big-O notation and worst case time complexity. In some specific cases I may explain average or best case time complexity.
