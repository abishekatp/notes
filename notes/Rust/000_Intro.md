# Rust

- In this series of blogs I will be trying to explain the core features of the Rust programming language in simple terms. 

- It will not be a in depth explanation of nook and corners of the language. If you are looking for that there are lot of resources for that already. Some of them are official [Rust book](https://doc.rust-lang.org/book/), [The standard library](https://doc.rust-lang.org/std/index.html), [Cargo book](https://doc.rust-lang.org/cargo/index.html) and there are many other resources which you can find in the [official website](https://www.rust-lang.org/)

- These blogs will be like a personal notes. Just explaining the bare minimum things to understand the core functionality of the language. Later if you want to go in depth to any language feature, then you can use the above resources.
